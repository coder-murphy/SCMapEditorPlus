## 能从中得到什么

- **25 个对话框模板** → 可直接导出为 `.rc` 里的 `DIALOG` 定义，包含每个控件的位置、尺寸、
  样式、文本和控件 ID。这是整份 UI 骨架里信息密度最高的部分。
- **主菜单（ID 109）+ 4 组加速键** → 完整菜单结构与快捷键。
- **位图（约 488 KB）** → 图标化工具条素材。
- **自定义 `BIN`** → 待确认用途（疑似内嵌的瓦片/调色板或帮助数据）。

## 导出状态（P3-12）

`tools/export_res.py` 可复现导出（仅逆向时使用，构建不依赖）：

```
python tools/export_res.py --exe "<星际安装目录>/[CN]ScmDraft2.exe"
```

输出到 `src/res/assets/`，已随仓库提供；日常编译不需要游戏目录：

| `bitmap_152.bmp` | 128×128，24 bpp | 图标 |

## BIN 用途确认（反汇编，VERIFIED）

对 `[CN]ScmDraft2.exe` 反汇编后按资源 ID 定位：

- `0x00406391: push 94h` → 分配 0x410 字节并写标签 `"VCOD"`；资源 148 即默认 VCOD 段。
- `0x0040C736 / 0x0040C73D`：同一标志为 0 时 `push 0B7h`（183），否则 `push 0C1h`（193）；
  取出的数据写入标签 `"TRIG"` 的新段（长度取资源大小）。TRIG 记录为 2400 B，
  因此 183 = 3 条、193 = 4 条默认触发；标志值为 2 时跳过（无 TRIG）。
- `0x0043D869: push 0AAh` → 资源 170 作为字符串表传给对象方法；内容为
  `Units/Zerg/...`、`... Death`、`... Explosion` 等名称，确认是单位/精灵名称树。

本工程 `res/assets.rc` 以 RCDATA 148/183/193 内嵌前三者；170 暂未使用。
