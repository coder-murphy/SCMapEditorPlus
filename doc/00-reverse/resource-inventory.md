## 能从中得到什么

- **25 个对话框模板** → 可直接导出为 `.rc` 里的 `DIALOG` 定义，包含每个控件的位置、尺寸、
  样式、文本和控件 ID。这是整份 UI 骨架里信息密度最高的部分。
- **主菜单（ID 109）+ 4 组加速键** → 完整菜单结构与快捷键。
- **位图（约 488 KB）** → 图标化工具条素材。
- **自定义 `BIN`** → 待确认用途（疑似内嵌的瓦片/调色板或帮助数据）。
