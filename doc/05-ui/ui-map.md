## 主菜单与加速键（P3-10，VERIFIED）

来源：`[CN]ScmDraft2.exe` 的 `RT_MENU 109`（8 888 B）与 `RT_ACCELERATOR 109/176/177/178`，
导出到 `src/res/menu.rc` / `src/res/accel.rc`，由 `resources.rc` include。

### MENU 资源格式（MENUEX 变体）

- 头 8 字节：`u16 version=1`、`u16 offset=4`、`u32 helpId`
- 每项：`u32 type`、`u32 state`、`u32 menuId`、`u16 resInfo`、文本（0 结尾 UTF-16）
- `menuId == 0xFFFF` 为弹出菜单；`resInfo & 0x01` 的项在文本后多 4 字节
- `resInfo & 0x80` = 当前层最后一项；弹出项带 0x80 时，其子菜单结束后还要关闭父层
- 每项按 4 字节对齐
- 资源尾部有 2 460 字节英文调试菜单残留（本地化后未清理的死数据），解析到顶层闭合即停

统计：**10 个顶层菜单 / 226 项 / 18 个分隔符**
（文件 编辑 选项 显示选项 剧本设置 高级 触发 窗口 帮助 调试；226 含本工程新增的「单位面板」与「选择工具」）。

## 本轮修掉的三个真实 bug

1. **103 打开失败（错误 1814）**：`resource.h` 的中文注释在 RC 的 CP936 解码下吞掉换行，导致第一条
   `#define IDD_DLG_103` 失效，RC 把该对话框编成**字符串名资源**，`MAKEINTRESOURCEW(103)` 因此找不到。
   处理：`resource.h` 注释改为纯 ASCII（保留 BOM）；重建后 25 个 ID 全为序号资源。
2. **187 富文本对话框**：模板含 `RichEdit20A`，需先注册窗口类 → `App::Run` 中 `LoadLibraryW(L"riched20.dll")`。
3. **103 的图标静态控件**：其文本是图标资源名 `"130"`，本工程不导出该图标，创建时会失败 → 从模板移除该控件
   （仅影响关于框图标显示）。

- 小雷达按 16 格网格放置（起点 16，覆盖约 10 格视野），同一玩家同位置不重复；
  单位数接近 1650 时停止并保留已放置部分。
- 迷雾只改目标玩家位，其它玩家位保持不变；“所有玩家”整字节填 0x00/0xFF。
- 两个操作都包在 `BeginEdit/CommitEdit` 中：小雷达进入 UNIT 快照，迷雾进入 MASK 快照。
- 无头回归 `--radar-test`：放置数量、重复跳过、删除、整图填位、撤销重做、
  保存重开与未编辑段保持。

## 装饰物 / 战争迷雾（P1）

- **装饰物**：解析 DD2（8 B/条），在编辑层“装饰物”或显示选项打开时，
  按 `(x,y)/32` 画品红空心标记；只读显示，放置/删除待装饰物面板。
- **战争迷雾**：解析 MASK（每格 1 B，bit0..7 对应玩家 1..8，1 = 迷雾）。
  显示选项或迷雾层打开时，对 bit0 为 1 的瓦片用 AlphaBlend 半透明黑色覆盖。
  迷雾层左键单击切换该格，拖动统一写入按下时的目标状态；一次拖动为一步撤销。
- **选项 → 战争迷雾 → 默认为未探索/已探索**（0x80D3/0x80D4）整图填充 0xFF/0x00。
- DD2/MASK 只在被修改时重写；重设地图尺寸时迷雾按偏移搬移，新增区域默认 0xFF。
- 无头回归 `--decor-test`：解析/逐字节往返、整图填充、修改、撤销重做、保存重开、
  其它装饰物与 THG2/UPGR/DIM/MTXM 保持。

## 编辑声音（198，P1）

入口：剧本设置 → 编辑声音（0x8047）。

- 列表 512 项对应 `WAV ` 段（`u32[512]`），显示每个槽的 STR 路径或“(空)”。
- 输入 WAV 路径后“设置”：复用现有 STR 下标；下标为 0/越界时追加新 STR 条目。
- “清除”把该槽的 STR 下标置 0；关闭即返回，整次会话进入撤销栈。
- 无头回归 `--scenario-text-test`。

## 任务简报（199，P1）

入口：触发 → 编辑任务简报（0x8110）。

- 解析 `MBRF`（2400 B/条，结构同 TRIG）；列表只列出已有的
  文本消息（3）/ 任务目标（4）/ 传输（8）行动。
- 选中后编辑文本并“更新文本”：写回 STR；字符串下标为 0 时自动分配。
- 不新增/删除/重排简报行动，保留原有结构；关闭即返回。
- 无头回归 `--scenario-text-test`。

## 开关命名（179，P1）

入口：触发编辑器 → “开关命名”按钮（1102），或按 ID 打开 179。

- 列表固定 256 项，对应 `SWNM` 的 `u32[256]` STR 下标；
  显示“开关 N: 名称”或“(默认)”。
- “设置”写入/复用 STR 下标；“还原”把该开关下标置 0（恢复默认名）。
- 修改实时写入地图，关闭触发编辑器时合并为一步撤销。
- 无头回归 `--scenario-text-test`。

## SP 单位（THG2，P1）

- 解析 THG2（10 B/条：类型/坐标/玩家/未用/标志），SP 单位层或显示选项打开时绘制青色标记。
- 标志 bit12（0x1000）为“按精灵绘制”：空心圆；否则空心方框。
- SP 单位层目前只读显示，点击不再误放普通单位；164 属性面板仍待实现。
- 只在被修改时写回 THG2；无头回归 `--sprite-test`（逐字节往返、异常长度、保存重开、未编辑段保持）。

## SP 单位属性（164，P1）

入口：窗口 → SP单位窗口（0x80A4），或 SP 单位层双击青色标记。

- 列表（1019）对应 THG2 记录，显示编号、类型、坐标、玩家与 `[SPR]`。
  切换列表项时先把当前控件写回上一条记录。
- 玩家下拉（1022）：Player 1..8 → THG2 owner 0..7。
- Bit0..Bit11（1023..1034）→ flags 低 12 位。
- Flipped（1035）→ bit13；激活/禁止（1036）→ bit15，勾选表示禁用。
- 普通SP / 单位SP（1039/1040）→ bit12 二选一：普通SP 置位（按精灵绘制）。
  资源中这两个按钮原为灰色，创建时启用。
- 编辑框 1037 → THG2 的未用字节（十六进制 0x00..0xFF）。
- 关闭按钮即应用；整次编辑进入撤销栈（THG2 快照）。164 资源没有独立“取消”，
  关闭窗口同样按应用处理。
- 回归：`--sprite-test`（字段修改、Flipped/禁用/bit12、撤销重做、保存重开）。

## 地点编辑（171，P1）

入口：
- 编辑层 → 区域/位置/Loc（Ctrl+L）后，双击地图上的地点矩形；
- 选项 → Locations → 修改名字（0x8108），编辑光标所在地点。

  其它地点记录与 UPGR/DIM/MTXM 保持不变。

## 玩家 / 势力设定（P1）

入口：剧本设置 → 势力设定（0x8042），打开 196。
